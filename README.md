# CycLocNet

Official repository for **CycLocNet (Cycle Localization Network): Density-Guided Repetition Cycle Localization**.

## Release Plan

Our paper, “Density-Guided Repetition Cycle Localization,” has been published in *IEEE Access*. The article is available on [IEEE Xplore](https://ieeexplore.ieee.org/document/11753574).

We are preparing the code and pretrained models for public release and will make them available soon.
